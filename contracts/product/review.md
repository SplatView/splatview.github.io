# Product contract bundle 1.0.0

Reviewed October 17, 2026 against the four current development workspaces. This is an independent contract revision, not an application version. The producer review is design/feature-reviews/contract-gap-implementation.md in the Windows source repository.

All native editors require the full feature families recorded here. Missing adapters or native evidence remain delivery gaps, never an implicit exclusion. Web-lite retains viewing, manual/color selection, cleanup, manual transforms/alignment, basic/auto color and create-copy export. Advanced algorithms stay in source but are not offered or dispatched in that profile. Browser fullscreen, clipboard and local persistence require actual host availability with the recorded fallback. Agent access/measurement and shell effects are excluded from web-lite.

Agent measurement is API-only; the legacy internal/CLI math/export compatibility feature is not an ordinary tool or tutorial. Native access starts disabled per launch, enabling copies the connection prompt, edits need no per-action approval, and saves never overwrite. Preview/thumbnail hosts use an explicit allowlist, not inherited desktop permissions.

Every local registered binding is classified explicitly by the consuming adapter and pinned to its review. Future members or changed declarations fail inventory validation; add/amend review and policy, then regenerate. Existing source locks, API/CLI/native tests, controllers, resource admission and history still apply. Bundle checks cannot establish native Apple, desktop/session, browser/GPU or installed-provider qualification.

Interactive preview hosts explicitly retain observational navigation, capture/copy/fullscreen, existing native view/thumbnail preferences, create-copy output, settings and document browsing/handoff through their current owners. File grants, sampling, host readiness and publication authority remain existing checks; this policy does not qualify an absent native implementation. Background thumbnail hosts receive rendering only. Preview hosts never expose the API surface, agent entry or editing/history tools. Ubuntu tutorial entry from Preview is an editor handoff, and promotion does not change its immutable Agent-origin exclusion.

## Revision 2.0.0: manual Paint and agent-only Clone

Reviewed October 18, 2026 in design/feature-reviews/paint-workflow.md of the Windows producer workspace. This major contract revision removes procedural Clone from human UI while preserving the existing gaussians.clone API identity, defaults and algorithms. New painting.clone is API-only; painting.manual registers typed human task/shape/target choices. Other painting.edit bindings and API technical parameters retain their meanings.

Both manual tasks retain draw/review/Apply/discard. Paint remains Pro. Explicit selected/scene target, local captured visibility, shared surface following, valid-prefix edge stopping, clean appearance, stable review actions and pending-work guards are required native behavior. Windows implements and qualifies this increment; missing macOS/Ubuntu portions remain explicit actionable port gaps. Web-lite authoring and read-only preview/thumbnail hosts remain excluded. Agent edits require no per-action approval; agent saves remain create-only.

All four adapters import the identical sealed successor and preserve source/native guards. Portable policy verification does not qualify AppKit/Metal, Linux desktop/GPU sessions, browser runtime or installed providers. No application version or legal text changes.
